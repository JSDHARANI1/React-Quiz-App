# 🎯 React Quiz App

An interactive quiz application built using React.js, React Router, and Tailwind CSS. Users can enter their name, answer questions, and view their final score.

---

## 🚀 Live Demo
👉 https://jsdharani1.github.io/React-Quiz-App/

---

## 📌 Features
- 🧠 Multiple-choice quiz questions
- 👤 User name input
- 📊 Score tracking
- 🔄 Navigation between pages (Home, Quiz, Result)
- 🎨 Responsive UI with Tailwind CSS

---

## 🛠️ Tech Stack
- React.js
- React Router DOM
- Tailwind CSS
- Vite
